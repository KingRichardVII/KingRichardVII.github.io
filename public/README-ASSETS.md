# Portfolio Asset Guide

## Profile photo

Current file:

    public/profile.webp

Replace this file while keeping the same filename.

Recommended:
- square image
- at least 600x600
- WebP
- professional headshot


## Favicon

Current file:

    public/favicon.svg

The current favicon is inherited from the Astrofy template.

Replace it before final deployment with Richard's own branding.

Recommended:
- simple design
- readable at very small sizes
- SVG preferred


## Social preview image

Current file:

    public/social_img.webp

This image is used when the portfolio is shared on platforms such as LinkedIn
or Discord.

Replace it with a portfolio-branded image before final deployment.

Recommended dimensions:

    1200 x 630


## Project images

Store project images under:

    public/projects/

Recommended structure:

    public/projects/homelab/
        thumbnail.webp
        architecture.webp
        screenshot-01.webp

    public/projects/linux/
        thumbnail.webp
        screenshot-01.webp

Project thumbnails should clearly communicate what the project is without
requiring someone to read a paragraph.
